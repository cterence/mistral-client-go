## Documentation For Authorization


Authentication schemes defined for the API:
### DashboardUserContextAuth

- **Type**: API key
- **API key parameter name**: x-api-key
- **Location**: HTTP header

Note, each API key must be added to a map of `map[string]APIKey` where the key is: DashboardUserContextAuth and passed in as the auth context for each request.

Example

```go
auth := context.WithValue(
		context.Background(),
		mistral.ContextAPIKeys,
		map[string]mistral.APIKey{
			"DashboardUserContextAuth": {Key: "API_KEY_STRING"},
		},
	)
r, err := client.Service.Operation(auth, args)
```

### BearerUserContextAuth

- **Type**: HTTP Bearer token authentication

Example

```go
auth := context.WithValue(context.Background(), mistral.ContextAccessToken, "BEARER_TOKEN_STRING")
r, err := client.Service.Operation(auth, args)
```

### DashboardUserOrServiceAccountContextAuth

- **Type**: API key
- **API key parameter name**: x-api-key
- **Location**: HTTP header

Note, each API key must be added to a map of `map[string]APIKey` where the key is: DashboardUserOrServiceAccountContextAuth and passed in as the auth context for each request.

Example

```go
auth := context.WithValue(
		context.Background(),
		mistral.ContextAPIKeys,
		map[string]mistral.APIKey{
			"DashboardUserOrServiceAccountContextAuth": {Key: "API_KEY_STRING"},
		},
	)
r, err := client.Service.Operation(auth, args)
```

### AdminApiKey

- **Type**: HTTP Bearer token authentication

Example

```go
auth := context.WithValue(context.Background(), mistral.ContextAccessToken, "BEARER_TOKEN_STRING")
r, err := client.Service.Operation(auth, args)
```

### ApiKey

- **Type**: HTTP Bearer token authentication

Example

```go
auth := context.WithValue(context.Background(), mistral.ContextAccessToken, "BEARER_TOKEN_STRING")
r, err := client.Service.Operation(auth, args)
```


## Documentation for Utility Methods

Due to the fact that model structure members are all pointers, this package contains
a number of utility functions to easily obtain pointers to values of basic types.
Each of these functions takes a value of the given basic type and returns a pointer to it:

* `PtrBool`
* `PtrInt`
* `PtrInt32`
* `PtrInt64`
* `PtrFloat`
* `PtrFloat32`
* `PtrFloat64`
* `PtrString`
* `PtrTime`
